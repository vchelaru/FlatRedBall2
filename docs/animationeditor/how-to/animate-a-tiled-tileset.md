## What Isn't Available in .tsx Projects

A Tiled tile animation stores only each frame's region and length, so these features are hidden in `.tsx` projects:

* Flipping animations and frames
* Frame offsets (Relative X and Relative Y) and **Adjust Offsets**
* Frame color (tint and alpha)
* Collision shapes

**Grid** is always on in `.tsx` projects, since frames map to tiles.
